
## Indoor Navigation Assistant (Proof of Concept)
#### Overview

This project is a university proof-of-concept Android application designed to explore how modern AI techniques can enhance accessibility for blind and visually impaired users.

The core idea is to combine:

- Large Language Models (LLMs) for natural, context-aware guidance
- Classical computer science algorithms (pathfinding and graph traversal)
- Structured indoor mapping data

to create an intelligent system capable of guiding users through indoor environments.

---

#### Project Aim

The goal of this project is to investigate whether integrating AI-driven reasoning with traditional pathfinding algorithms can improve indoor navigation experiences where GPS is unreliable or unavailable.

This application focuses on:

- Generating step-by-step navigation instructions
- Interpreting user queries in natural language
- Adapting routes dynamically based on context
